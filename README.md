# Beppe Barber

Sito statico multilingua per beppebarber.com. HTML, CSS e JavaScript senza compilazione.

## Struttura
- `/`: italiano
- `/en/`, `/de/`: inglese e tedesco
- `/prodotti/`, `/en/products/`, `/de/produkte/`: catalogo
- `/privacy-policy/`, `/cookie-policy/`: informative
- `/fonts/`: font locali

## Da completare prima del passaggio del dominio
- Recuperare le 14 immagini ancora ospitate su WordPress e aggiornare i riferimenti.
- Inserire il link reale Google Calendar al posto di `INSERISCI-ID-PRENOTAZIONE` nelle tre home.
- Collegare e verificare l'hosting Cloudflare prima di modificare DNS o dismettere SiteGround.

La radice del repository contiene i file pubblicabili. Non sono necessari database o WordPress.
